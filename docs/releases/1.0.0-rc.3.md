# The Herbal Witch 1.0.0-rc.3

## GuideME Phase 1: My first useful herb

The Witch's Path now introduces lavender and valerian through drying, grinding and kettle
brewing to a Restful Infusion. Hold G over the lesson's herbs, ingredients, drink or stations
to open the native GuideME lesson. Crafting cards and live processing cards use current recipes;
missing processing recipes are shown as unavailable. Rotatable drying-rack and heat scenes use
the real block models and complete layouts.

Requires **GuideME 20.1.15** on both client and server, installed separately. The original grimoire,
discoveries, research and teaching remain unchanged. Existing saved IDs and protocol 14 remain
unchanged. Ponder and the replacement reader are not included in this additive first phase.

The mod also has its own logo. Shared CI now verifies the release jar and generated resources;
publishing remains a deliberate, owner-authorized workflow after green main CI and GameTests.

This is a private release candidate. Owner acceptance of guide navigation, rotation, GUI scales
and following the full lesson is pending; these notes do not constitute release approval.
